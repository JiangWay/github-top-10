## 每日一字

# 跨界（Crossover）

「跨界」不是隱喻，是今日榜單的骨架。三個具體訊號：

- **廠商跨界**：[openai/codex-plugin-cc](https://github.com/openai/codex-plugin-cc) 是 OpenAI 官方發布的 plugin，走 Anthropic 的 Claude Code plugin marketplace 分發，讓使用者在 Claude session 內叫 Codex 做 code review。這是「敵對陣營主動送 plugin 進對手主場」的第一個大規模案例——不是 wrapper、不是 fork，是官方維護。
- **技術路線跨界**：[alibaba/page-agent](https://github.com/alibaba/page-agent) 走「不 headless browser、不截圖、不 vision model」的反 [browser-use/browser-use](https://github.com/browser-use/browser-use) 路線，把 agent 拉回 client-side JS runtime，用 DOM 文字化讓小模型也能操作頁面。[Zackriya-Solutions/meetily](https://github.com/Zackriya-Solutions/meetily) 則把 Otter / Fireflies 這類雲端 SaaS 移進本機 Rust + Tauri，同時 diarization 走 NVIDIA sortformer 而非主流 [pyannote/pyannote-audio](https://github.com/pyannote/pyannote-audio)。
- **領域跨界**：[rommapp/romm](https://github.com/rommapp/romm) 不是 emulator（[libretro/RetroArch](https://github.com/libretro/RetroArch) 那類），是「Jellyfin for ROMs」——把媒體庫的架構套到遊戲檔上。[harvard-edge/cs249r_book](https://github.com/harvard-edge/cs249r_book) 是把 ML 教材從「模型演算法」（[d2l-ai/d2l-en](https://github.com/d2l-ai/d2l-en) 路線）跨到「系統設計 + 硬體佈署 + 責任 AI」的完整系統論述。

榜單另外 3 檔（[usestrix/strix](https://github.com/usestrix/strix)、[JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman)、[mattpocock/skills](https://github.com/mattpocock/skills)）雖非 crossover 本身，但 strix 是 6-30 唯一續榜者、caveman 與 mattpocock/skills 屬同一 Claude Code Skill 生態——三者一起把「跨界」的邊界撐開成榜單主題。
